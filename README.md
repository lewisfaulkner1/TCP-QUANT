# TCP-QUANT

TCP — The Crypto Playbook.

| Folder | What's inside |
|---|---|
| `brand/` | Official logo pack, intro videos, captions and the brand guide |
| `community/` | Telegram kit for the TCP Inner Circle: description, welcome, rules, post formats and banner |
| `bot/` | The onboarding bot (link in bio → 18+ check → broker → Inner Circle invite) and its setup guide |
| `terminal/` | The Quant Terminal: a members-only Telegram Mini App with live charts, the probability engine, a risk calculator and prop challenge simulator, the Playbook (Lewis's setups, logged before the result and tracked to the end), session briefs (Lewis's charts read by TCP AI before each session, checked by him, and every zone scored afterwards), and the leaderboard (members' MT5 results as percentages, read-only) |
| `bridge/` | The TCP bridge for a Windows PC with MT5: reads connected members' accounts with their investor passwords and sends the terminal daily percentages, never balances |
| `tools/card-studio/` | TCP Card Studio: branded signal and weekly-results images with matching captions |
| `signals/` | Signal publisher for the VPS: posts the algorithm's signals, updates and weekly results into Telegram as branded cards |
