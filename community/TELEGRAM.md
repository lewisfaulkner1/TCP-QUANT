## Signal post format

Use the same format every time, so members can read a signal at a glance.

```
📈 SIGNAL · [date]

Market: XAUUSD
Direction: BUY / SELL
Entry: [price]
Stop loss: [price]
Take profit: [price]
Risk:Reward: 1:[R]
Why: [one line]

Updates follow as replies until the trade is closed.
Not financial advice.
```

## Weekly results format

"Transparent results" only builds trust if every trade is in it.

```
📊 WEEKLY RESULTS · [dates]

Trades: [n]
Wins: [n] · Losses: [n]
Net: [+/- R]

Every trade from the week is listed below, wins and losses.
Past performance is not a guide to future results.
```
